🧪 Teste Manual - Exportação CSV

Interface para testar manualmente a geração e formatação de CSV

Teste 1: Formatação de Valores ✓ ESPERADO PASSAR

Resultado aparecerá aqui...
Casos de teste inclusos:
✓ Valores simples: "SimpleCategory" → "SimpleCategory"
✓ Com vírgula: "Consultória, Design" → "\"Consultória, Design\""
✓ Com aspas: 'Test "quoted"' → '"Test ""quoted"""'
✓ Números: 1234.5 → "1234.50", 500 → "500.00"
✓ Acentos: "Análise" → "\"Análise\""
